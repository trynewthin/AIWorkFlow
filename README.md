# AIWorkflow 智能工作流平台

![AIWorkflow Platform](./public/images/1.png)

`AIWorkflow` 是一个强大的桌面端智能工作流自动化平台，旨在帮助用户通过可视化的方式构建、管理和执行复杂的AI驱动的工作流。它集成了知识库管理、多样的功能节点和灵活的流程编排，为实现复杂的自动化任务提供了完整的解决方案。

## 核心功能

- **可视化工作流编排**：提供直观的拖拽式画布编辑器，用户可以轻松地将不同的功能节点连接起来，构建出强大的工作流。
- **智能节点库**：内置多种类型的AI及功能节点，例如：
  - **大语言模型节点**：与大语言模型进行交互，用于内容生成、摘要、问答等。
  - **向量嵌入节点**：将文本数据转换为向量，是构建知识库检索的基础。
  - **知识库检索节点**：从指定的知识库中检索与输入最相关的信息。
  - **Web请求节点**：与其他系统进行API交互。
- **知识库管理**：支持创建和管理多个知识库。用户可以上传文档，系统会自动进行分片、向量化，并存入本地向量数据库，以便在工作流中进行高效的语义检索（RAG）。
- **用户与多租户管理**：内置基础的用户管理系统，为后续的团队协作和权限隔离提供支持。

## 架构设计

`AIWorkflow` 采用前后端分离的架构，并通过 Electron 将其封装为跨平台的桌面应用程序。

```
+--------------------------------+
|       Electron 主框架          |
|  +--------------------------+  |
|  |     前端 (渲染进程)      |  |
|  |  +--------------------+  |  |
|  |  | React, Vite, ...   |  |  |
|  |  +--------------------+  |  |
|  +--------------------------+  |
|               ^                |
|               | (IPC 通信)     |
|               v                |
|  +--------------------------+  |
|  |      后端 (主进程)       |  |
|  |  +--------------------+  |  |
|  |  | Node.js, Express   |  |  |
|  |  | (模块化服务)       |  |  |
|  |  +--------------------+  |  |
|  +--------------------------+  |
+--------------------------------+
```

### 技术栈

- **应用框架**: [Electron](https://www.electronjs.org/)
- **前端**:
  - UI框架: [React](https://reactjs.org/)
  - 构建工具: [Vite](https://vitejs.dev/)
  - UI组件库: [shadcn/ui](https://ui.shadcn.com/) (推断)
  - 样式: [Tailwind CSS](https://tailwindcss.com/)
- **后端**:
  - 运行环境: [Node.js](https://nodejs.org/)
  - 核心框架: 基于 `ee-core` 进行封装
- **数据库**:
  - 向量存储与搜索: [HNSWlib](https://github.com/nmslib/hnswlib)
  - 业务数据: 本地文件/轻量级数据库

### 后端架构

后端在 Electron 的主进程中运行，采用了高度模块化的设计，主要逻辑位于 `electron/module/` 目录下。

- **分层设计**: 遵循 `Controller -> Service -> Database` 的经典分层模式。
  - `controllers`: 负责接收来自前端的IPC请求，并进行参数校验。
  - `services`: 核心业务逻辑层，处理具体的功能实现。
  - `database`: 数据持久化层，负责与本地数据库或文件系统交互。
- **核心模块 (`electron/core/`)**: 提供 `BaseController`, `BaseService` 等基类，统一了模块开发规范，提高了代码的可复用性。
- **IPC接口 (`electron/api/`)**: 统一管理和暴露所有对前端的IPC接口，是前后端通信的桥梁。

### 前端架构

前端负责提供用户交互界面，运行在 Electron 的渲染进程中。

- **组件化开发**: 使用 React 进行组件化开发，UI组件位于 `frontend/src/components/`。
- **服务层 (`frontend/src/services/`)**: 封装了对后端IPC接口的调用，将数据请求与UI组件解耦，使得业务逻辑更加清晰。
- **路由管理 (`frontend/src/router/`)**: 使用 `react-router-dom` 管理页面路由，实现单页应用（SPA）的流畅体验。

## 模块概览

- **Workflow**: 工作流模块，负责工作流的创建、编辑、保存和执行的核心逻辑。
- **Knowledge**: 知识库模块，管理知识库的增删改查、文档上传、文本切分和向量化处理。
- **Node**: 节点模块，定义了所有工作流节点的基类和具体实现，是工作流执行的基本单元。
- **User**: 用户模块，处理用户登录、认证和基本信息管理。
